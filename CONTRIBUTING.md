# Contributing

Thank you for your interest in contributing to Assochemm.

How to contribute
1. Fork the repository.
2. Create a branch for your work: `git checkout -b feat/your-feature`.
3. Make changes and write tests where appropriate.
4. Commit and push your branch to your fork.
5. Open a Pull Request describing the change.

Code style
- This project follows standard Dart/Flutter formatting and lints. Run `dart format .` before committing.

Reporting issues
- Use the repository Issues page to report bugs or request features. Include reproduction steps and device details if applicable.
